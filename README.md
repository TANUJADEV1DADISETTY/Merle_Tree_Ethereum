# Build a Merkle Tree in Python to Verify Ethereum Transactions

## Overview

This project implements a complete Merkle Tree system in Python and demonstrates how Ethereum transaction inclusion verification works using Merkle proofs.

The project covers:

- Building a Merkle Tree from scratch
- Generating and verifying Merkle proofs
- Fetching real Ethereum block data using JSON-RPC
- Reconstructing transaction roots
- Verifying transaction inclusion
- Docker containerization

This project demonstrates the core cryptographic concept used in blockchain systems to ensure data integrity and trustless verification.

# Core Concepts

## What is a Merkle Tree?

A Merkle Tree is a binary tree where:

- Leaf nodes contain hashes of data
- Internal nodes contain hashes of child nodes
- The top hash is called the Merkle Root

Any change to data changes the root hash, making tampering detectable.

---

## Why Blockchain Uses Merkle Trees

Ethereum uses Merkle structures to:

- Verify transaction inclusion
- Enable light clients
- Reduce verification data size
- Ensure blockchain integrity

Each Ethereum block contains a `transactionsRoot` field which is a cryptographic commitment to all transactions inside the block.

# Implementation Details

# Part 1 - Merkle Tree

## SHA-256 Pair Hashing

Each parent node is generated by:

```python
sha256(left_hash + right_hash)
```

---

## Odd Leaf Handling

If a tree level has an odd number of nodes:

- Duplicate the final node
- Continue tree construction

Example:

```text
[A, B, C]
becomes
[A, B, C, C]
```

---

## Proof Generation

A Merkle proof contains:

- Sibling hashes
- Sibling positions (left/right)

Example:

```python
[
    {
        "hash": b"...",
        "position": "left"
    }
]
```

---

## Proof Verification

Verification steps:

1. Hash target leaf
2. Combine with sibling hashes
3. Recompute root
4. Compare against expected root

# Part 3 - Transaction Verification

## Simplified Hashing

This project initially uses:

```python
SHA256(transaction_hash)
```

This validates Merkle logic but does not exactly match Ethereum's internal trie structure.

---

## Accurate Ethereum Hashing (Extension)

Ethereum actually uses:

- RLP encoding
- Keccak-256 hashing
- Merkle Patricia Trie

Optional extension support is included.
